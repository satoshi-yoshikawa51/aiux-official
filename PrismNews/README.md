# Prism — パーソナライズドニュース iPhoneアプリ

Yahoo!ニュースのような体験を、自分の好みに完全に合わせて。
読むほどに「おすすめ」が賢くなる、ダークデザインのSwiftUIニュースアプリです。

## 特徴

- **おすすめフィード** — 「いいね」「興味なし」「閲覧履歴」の3つのシグナルから好みを学習し、記事を自動で並べ替え。記事タイトルを日本語の分かち書き（NaturalLanguageフレームワーク）でキーワード分解して興味を推定します。
- **Yahoo!ニュース全カテゴリ** — 主要・国内・国際・経済・エンタメ・スポーツ・IT・科学・地域の公式RSSを並列取得。**APIキー不要で、ビルドしてすぐ動きます。**
- **キーワードフォロー** — 「生成AI」「推しの名前」など、フォローした語を含む記事を大きく優遇。
- **あとで読む** — ブックマークを端末内に保存。
- **検索** — 読み込み済み記事の即時検索。[gnews.io](https://gnews.io) の無料APIキーを設定すると、Web全体のニュース検索も可能（任意）。
- **洗練されたダークUI** — 漆黒の背景にミント×ブルーのグラデーションアクセント。アプリ内ブラウザ（SFSafariViewController）もダーク統一。

## 動かし方

1. **Mac の Xcode 16 以降**で `PrismNews/PrismNews.xcodeproj` を開く
2. Signing & Capabilities でご自身の Team を選択（Bundle Identifier `com.example.PrismNews` は適宜変更）
3. iPhoneシミュレータまたは実機を選んで ⌘R

初回起動時に興味のあるジャンルとキーワードを選ぶオンボーディングが表示されます。

## アーキテクチャ

```
PrismNews/
├── Models/        Article, NewsCategory
├── Services/
│   ├── YahooNewsService   Yahoo!ニュースRSSの取得
│   ├── RSSParser          RSS 2.0 パーサー（XMLParser）
│   ├── GNewsService       GNews API（検索・任意）
│   ├── OGImageLoader      記事ページのog:imageからサムネイル取得
│   └── Tokenizer          日本語タイトルのキーワード分解
├── Stores/
│   ├── NewsStore          記事の取得・集約・おすすめ並べ替え
│   └── UserStore          好みの学習と永続化（profile.json）
└── Views/         ホーム / 検索 / あとで読む / 設定 / オンボーディング
```

## パーソナライズの仕組み

各記事に「好みスコア」を付けて並べ替えます。

| シグナル | 重み |
|---|---|
| 興味ジャンルに一致 | +1.5 |
| フォロー中キーワードがタイトルに含まれる | +2.5 |
| 学習済みキーワードの一致 | 最大 ±1.5 |
| 学習済みカテゴリの好み | 最大 ±2.0 |
| 新着（24時間で減衰） | 最大 +1.5 |
| 既読 | −1.5 |

記事を長押しして「いいね」するとタイトル中のキーワードの重みが上がり、「興味なし」で下がります。記事を開くだけでも弱い正のシグナルになります。学習データはすべて端末内（Documents/profile.json）に保存され、外部送信はありません。
