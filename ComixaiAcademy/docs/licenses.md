# 同梱アセットの権利まわり（公開前の棚卸し）

ストアに出す＝**再配布**なので、アプリに同梱しているものを全部並べて、
出どころとライセンスを確認した。**「要確認」が残っているうちは提出しない。**

## 要確認（ユーザーにしか分からないこと）

### 1. BGM 3曲（`assets/music/home.mp3 / lesson.mp3 / game.mp3`）

曲名は「午後のカフェ」「アフタヌーンティー」「light_song」（README記載）。
**どこで入手した曲か・その配布元の規約**を確認してほしい。フリーBGMサイト
（甘茶の音楽工房・DOVA-SYNDROME・MusMus等）は多くがアプリ同梱OKだが、
**サイトごとに「クレジット表記の要否」「アプリ組み込みの可否」が違う**。

- [ ] 配布元のサイト名と曲ページのURLを控える
- [ ] アプリへの同梱（再配布）が許可されているか
- [ ] クレジット表記が必要か。必要なら設定画面かサポートページに載せる

### 2. 3Dアバター 12体（`assets/models/*.glb`）— Tripo製

Tripoの利用規約では、**生成時のプランによって商用利用の条件が変わる**
（有料プランは商用利用可・生成物の権利はユーザー帰属。無料枠は条件が異なる場合がある）。

- [ ] 生成した当時のTripoのプラン（無料/有料）を確認
- [ ] 有料プランなら問題なし。無料枠だった場合は、Tripoの現行規約で
      無料生成物のライセンス（CC BY等）を確認し、必要ならクレジットを載せる

### 3. 舞台背景 10枚（`assets/stages/`）— Midjourney製

Midjourneyは**有料プラン契約者が生成した画像は商用利用可**（規約 4. Copyright and Trademark）。

- [ ] 生成時に有料プランだったことを確認（たぶんYesのはず。Yesならこの項は完了）
