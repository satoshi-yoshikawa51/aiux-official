# 相棒の顔サムネイル

相棒をえらぶ画面（オンボーディング／せってい／ガチャの「あつめたアバター」）で、
左に出す丸い顔。**手で描いたものではなく、3Dモデルを焼いた画像**。

## 焼き直しかた

```bash
node tools/make-faces.mjs
```

`assets/models/` の GLB とテクスチャを読んで、顔だけを 256×256（透過PNG）で撮る。
モデルやテクスチャを差し替えたら、**これを流し直す**（古い顔が残る）。

## なぜ静止画なのか

一覧には13体ぶんが並ぶ。`Avatar3D` を13個置くとWebGLのコンテキストが足りない
（同時に持てるのは十数個で頭打ち）。ここは「顔が分かればいい」場所なので静止画で足りる。

## キャラを足したら

1. `tools/make-faces.mjs` の `LOOKS` に1行足す
2. `node tools/make-faces.mjs` を流す
3. `src/data/avatars.ts` の該当キャラに `face: require('@/assets/faces/<id>.png')` を足す

3を忘れても画面は壊れない。`face` が無いキャラは、これまでどおり色の丸になる
（→ `src/components/avatar-face.tsx`）。

## 顔の位置

**割合の決め打ちでは切れる。** この人たちはデフォルメで頭が大きく、頭が全高に
占める割合は27〜49%とキャラごとにばらばら。`make-faces.mjs` は `Head` の骨の
ワールド座標と、全身の外接箱の上端の差を「頭の高さ」として測っている。
