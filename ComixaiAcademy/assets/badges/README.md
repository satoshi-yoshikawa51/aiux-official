# バッジの絵

`src/data/badges.ts` の `art` から `require('@/assets/badges/<バッジID>.png')` で読む。
**置いて、台帳に1行足すだけ**で絵に切り替わる。入れていないバッジは
これまでどおりアイコン（`icon`）が出るので、1枚ずつ進められる。

| | |
|---|---|
| ファイル名 | バッジIDと同じ（`avatar-set.png` `role-set.png` …） |
| 形 | **正方形**。円い勲章でも、外接する正方形で書き出す |
| 大きさ | **512×512**。画面では最大120ptなので、@3xでも足りる |
| 形式 | PNG・**背景は透過**（コマは白い紙の上にも、黒い帯の上にも乗る） |
| 余白 | 絵の外に余白を入れない。四辺いっぱいに描く（表示側で余白を取る） |
| 影 | 落ち影は**焼き込まない**。紙の上で浮いて見える |

正方形でなかったり余白が付いていても、入れるときに**絵の外接矩形を測って
正方形に切り直す**（辺の約93%を絵が占める形に揃える）。ここを揃えないと、
余白の多い1枚だけ一覧で小さく見える。

## 未獲得のときは出さない

伏せてあるバッジは鍵のアイコンのままにしてある。**取る前に絵を見せると、
取った瞬間の驚きが無くなる**ので、ここは絵を入れても変えない。

## 描くときの当たり

`desc`（獲得条件）が絵の主題。「相棒えらび＝アバターを選んだ」なら握手、
「配属決定＝職種を選んだ」なら方位磁針、というふうに、**条件が一目で分かる
モチーフ**を1つだけ置く。

## 色は系統で分ける

**台座（金の月桂樹＋外枠）は全部で共通**。変えるのは中の面と帯の色だけ。
これが揃っていないと、25枚が別々の勲章の寄せ集めになる。

| 系統 | 色 | バッジ |
|---|---|---|
| はじまり | 青 | `avatar-set` `role-set` `first-lesson` |
| コース修了 | 緑 | `course-basics` `course-work` `course-prompt` `course-risk` `course-next` |
| 腕前（ノーミス・★3） | 赤 | `quiz-perfect` `quiz-perfect-5` `star-first` `star-5` `star-all` |
| 続ける・直す | 橙／琥珀 | `streak-3` `streak-7` `half` `review-first` `review-10` |
| 完走 | **金一色**（面まで金） | `all-clear` `perfect-all` |
| おまけ（ガチャ） | 紫 | `extra-first` `extra-3` `extra-5` `extra-sr` `extra-all`（殿堂だけ玉虫） |

取る順は人によって違うので、**称号（バッジの個数で決まる）では色を分けない**。
