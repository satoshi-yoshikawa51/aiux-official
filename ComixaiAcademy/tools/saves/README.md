## `all-clear.json`

**全レッスン修了・全★3・舞台とアバターを全部所持・おまけ全クリア・99P**
の状態。せっていの「記録を読み込む」に貼ると、その状態から始められます。

追加した舞台やおまけを実機で見るときに使います。本編17本を通してガチャを
何十回も回す代わりに、これ1枚。

▍iPhoneでの使い方

1. GitHubでこのファイルを開いて **Raw** を押し、全部コピー
2. アプリの **せってい → 記録の持ち出し → 記録を読み込む** に貼る
3. 「中身を見る」→「入れ替える」

▍**アプリの中から作るほうが確実**

せっていの「確認用」に **「全部そろった状態にする」**（その場で当てはめる）と
**「その記録をコピー」**（同じものを文字列で書き出す）があります。
そちらは**その時点の台帳から組み立てる**ので、舞台やおまけを足した直後でも
必ず最新です。

**このファイルは書き出した時点のもの**なので、景品を増やしたら古くなります。
更新するときは、アプリの「その記録をコピー」で取り直して貼り替えてください
（作っているのは `src/lib/dev-save.ts`）。
