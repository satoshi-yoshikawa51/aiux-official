# サイバー攻撃防災手帳（/bousai）の手順カード

手順カードは `src/app/bousai/data.ts` の `CARDS` に固定で持つ。AIには書かせない。
2026年10月17日に、各サービスの公式ヘルプ（Web検索で取得できた範囲）と当時の42枚を突き合わせ、
項目名・階層・事実関係を修正した。**実機では未検証**なので、確かめたカードから
`verified: "YYYY-MM-DD"` を入れること（画面の表記が「実機確認：…」に変わる）。

## 照合で直した主なもの（2026年10月）

- Apple：「Apple ID」→「Apple Account」。パスワードアプリの警告は「再利用」「安全性が低い」「漏洩」
- Google：アカウント画面のタブは「セキュリティとログイン」。2段階認証・パスワードは「Googleにログインする方法」欄
- Android：パスワードマネージャーは 設定 → Google → すべてのサービス → 自動入力とパスワード → Google自動入力。「デバイスを探す」は「Find Hub」
- Microsoft：2段階認証は セキュリティ → 「サインイン方法の管理」。履歴は「最近のアクティビティ」。Edgeのパスワードは 設定 → パスワードとオートフィル → Microsoft パスワード マネージャー（Walletは2025年5月に廃止）
- Windows：「BitLocker」は機種差ではなくエディション差。サインインを求めるタイミングは「毎回」
- LINE：「WEBログインの2要素認証」。認証番号はPC画面に出てスマホに入力する
- X：SMS認証はPremium限定（現在も）。Instagram/Facebookは「アカウントセンター」
- Discord：二要素認証は マイアカウント → パスワードと認証。DMは コンテンツ・ソーシャル → ソーシャル権限。公式ドメインは discord.com 以外もある
- 楽天：利用者がオンにする「2段階認証」はなく、現行は「パスキー」。ログインアラートは自動送信
- Yahoo! JAPAN：認証アプリは非対応（SMS認証・パスキー）。ログインアラートはオン/オフ不可
- メルカリ：「ログインセキュリティ」の項目はなく、現行は「パスキー設定」。「ログイン履歴」で強制ログアウトできる
- ゲーム：Nintendoは「ログインとセキュリティ → 二段階認証」。子どもアカウントには設定不可。PS4は階層が別。SteamはSteam Guardの「モバイル認証」を足す
- PayPay：項目名は「端末の管理」（旧「ログイン管理」）
- 証券：3社ともログイン時の多要素認証を必須化済み。SMS/メールのワンタイムパスワードは日証協ガイドライン（2025年10月改正）で有効な対策から外れ、パスキーに移行。「デバイス認証」はSBIで終了
- クレジットカード：「ご利用速報」という名称は無い。楽天・イオンは500円未満の利用は通知されない
- 携帯キャリア：dアカウントは「2段階認証設定を変更する → 強（推奨）」、au IDは会員情報サイトの「ログインとセキュリティ」、My SoftBankは「セキュリティの設定」。「決済サービス設定」という名称は3社とも無い
- マイナポータル：「ログイン履歴」ではなく「その他の履歴 → 利用履歴」。アプリ名は「マイナアプリ」。紛失時は「一時利用停止」
- Google Drive（スマホ）：一般的なアクセスは 共有 ではなく「アクセスを管理」。「共有アイテム」は他人から来たものの一覧
- Slack：連携アプリは ワークスペース名 → ツールと設定 → アプリを管理。Zoomの2段階認証はPro以上かつメール＋パスワードのサインインのみ
- Claude：個人アカウントに2要素認証の設定は無い（Googleログイン／メールリンク）
- 事例：「顧客リストをChatGPTに貼った」の実例は確認できず、サムスン電子（2023年）の例に差し替え

## 照合していないカード（2026年10月17日の照合後に追加）

仕事の分類を7つに広げたときに足した7枚は、公式ヘルプとの照合をまだしていない。
一般的な設定場所を書いているが、サービス名を挙げている箇所は項目名の確認が要る。

- crm_2fa（Salesforce・HubSpot・freee・Shopify・Stripe の2段階認証の場所）
- dev_2fa / dev_keys（GitHub の Two-factor authentication と Secret scanning、AWS の MFA と Budgets、Vercel の Spend Management）
- site_ops（WordPress の2段階認証プラグイン、Google広告・Meta広告のアクセス権、X の委任）
- nocode_check（Zapier の Apps、Make の Connections、Google の「サードパーティ製のアプリとサービス」）
- byod_rules、subs_check（一般論のみ）

## 実機で確かめたいもの（検索では確定できなかった）

- iPhone：「アカウントの復旧」の日本語の中間項目名、パスワード変更ボタンの表記（「パスワードの変更」か「パスワードを変更」か）、メールアプリでのリンク長押し
- Mac：メールで差出人名にカーソルを乗せたときのアドレス表示
- Android：Galaxyでのパスワードマネージャーの経路、Gmailでのリンク長押しのメニュー名
- Windows：設定 → ユーザーの情報 のリンク名、Outlookの「報告」ボタンの日本語表記、サインインを求めるタイミングの選択肢の字句
- Amazon：アプリ下部タブの名称、2段階認証のボタンの日本語表記、「ログイン中の端末」画面の正式名称
- 楽天：my.rakuten.co.jp の「会員情報」内のメニュー名
- メルカリ：売上金・ポイントの通知設定、お問い合わせの分類名
- PlayStation / Steam：日本語UIでのボタン名
- X / Facebook / Discord：日本語UIのラベル（「連携しているアプリ」「ログインの場所」「パスワードと認証」）
- 証券：マネックスのログイン通知設定、3社の「取引通知」の有無
- 銀行アプリ：「入出金通知」「ログイン通知」の項目名（銀行ごとに違う）
- My SoftBank：2段階認証に相当する設定の有無
- マイナンバーカード：4桁の暗証番号を「覚えていて任意に変更」する操作がコンビニで可能か
- Claude：2026年10月までにパスワード／パスキー方式が追加されていないか
