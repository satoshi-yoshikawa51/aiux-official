# 4コマで学ぶAI（手描き4コマの入稿ガイド）

用語集とプロンプト集のページに、吉川さんの手描き4コマを載せる仕組み。
**データファイルの編集は不要。決まった場所にPNGを置いてコミットするだけ**で、
該当ページとギャラリー（`/yonkoma`）に自動で載る。

ネーム・ネタ作りは人間（吉川さん）の仕事。仕組みは配ることだけを受け持つ。

## 流れ

```
1. 描く対象を決める   npm run yonkoma:list        （slugと入稿済み✔の一覧）
2. 描く              ネームから自分で
3. 置く              public/yonkoma/glossary/rag.png
4. コミット＆push     デプロイされたら用語ページとギャラリーに出ている
5. （任意）          npm run yonkoma:video -- rag でショート動画
```

## 置き場所の規約

| 置く場所 | 何が起きるか |
|---|---|
| `public/yonkoma/glossary/<slug>.png` | 用語ページ（/glossary/…）の定義カード直後に4コマが出る |
| `public/yonkoma/prompts/<slug>.png` | レシピページ（/prompts/…）の導入直後に4コマが出る |
| `public/yonkoma/og/<glossary\|prompts>/<slug>.png` | （任意）そのページのOGP画像を差し替える。1200×630 |

- 拡張子は `.png` か `.webp`。slugは各 `data.ts` のもの（`npm run yonkoma:list` で確認できる）
- OGP差し替えは任意。置かなければ既定のタイポグラフィOGのまま
- 入稿したら `npm run img:optimize` で軽量化しておくとよい

## 絵の仕様

- **縦読みの4コマ1枚画像**。幅1080px以上を推奨（ページでは最大約680pxで表示）
- 縦横比は自由。コマ間の余白・枠線も含めて1枚に描き出す
- ラフ絵で構わない。毎回描き下ろしシリーズなので、続けられる線で
- 出典表記は不要（ニュースではなくエバーグリーンな解説なので）

## 描く順番のヒント

- **プロンプト集（24本）から始めるのがおすすめ**。「ダメな指示→事故る→直す」という
  素材がすでにコメディの形をしていて、24本は描き切れる数だから
- 用語集は `npm run sc:report` でSearch Consoleの実データを見て、
  表示回数が多いのに順位が伸びていない語から描くと、効果が数字で見える
- 4コマがXでシェアされたとき用に、OGP差し替え（1コマ目を横長に切り出したもの等）を
  一緒に入稿すると効きが良い

## ショート動画にする（YouTube Shorts / TikTok / Reels / X 共用）

入稿済みの4コマは、1コマンドで縦型ショート動画（1080×1920・約24秒）になる。

```bash
npm install --no-save ffmpeg-static   # 初回だけ（ffmpegがPATHにあれば不要）
npm run yonkoma:video -- sales-email
```

- 出力は `yonkoma-videos/<slug>.mp4`（gitignore済み。アップロードしたら消してよい）と、
  タイトル・説明文・タグの下書き `<slug>.txt`
- 中身：コマの**黒枠を画像から自動検出**→1コマずつ表示→読み終わるたびに
  **右から左へ紙をめくる演出**（めくりSE同期）→4コマ目の後に**図解＋一文説明のカード**
  （用語ページと同じSVG図解。先に `npm run build` しておくと入る）
  →「解説の続きは comixai.dev/…」のエンドカード。ヘッダーはシリーズロゴ（`public/yonkoma/logo.webp`）
- `scripts/yonkoma-bgm.mp3` に権利クリアな音源を置くと小音量でBGMが入る（無ければSEのみ）
- 枠が検出できない絵（自由レイアウト等）は、全体をゆっくりスクロールする構成に自動で落ちる。
  コマ位置を手で教えるには、絵の隣に `<slug>.panels.json` を置く：
  `[{"top":120,"bottom":640},{"top":660,"bottom":1180}, …]`（元画像のピクセル座標）

**動画映えのコツ**：横に長いコマ（1080×430など）は縦画面で上下が空く。
動画も見据えるなら、コマを正方形に近め（1080×700前後）に描くと画面が埋まる。
APIは使わないので費用ゼロ。アップロードは手動（続くようならYouTube API自動化を検討）。

## ギャラリーについて

`/yonkoma` は入稿済みの4コマが新しい順に並ぶ棚。1本も無い間は「描き下ろし中」の
表示になり、sitemapにも載らない（1本入ると自動で載る）。
ある程度たまったら `site-chrome.tsx` のナビに「4コマ」を足すとよい（1行）。
