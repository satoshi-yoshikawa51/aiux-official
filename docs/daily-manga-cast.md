# 日刊4コマ（/daily）のキャラ素材

毎朝の4コマは、**絵を毎日描かない**作りになっています。
キャラクターの表情差分をあらかじめ用意しておき、コマ割りのテンプレートに
流し込んでPNGに焼く、という手順です。だから毎朝ぶんの手間はゼロになります。

素材の置き場所は `public/daily/cast/`。ファイル名だけで自動的に拾われます。

## ファイル名

```
public/daily/cast/<キャラ>-<表情>.webp   （.png でも可）
```

置いた瞬間からそのコマで使われ、無いものは仮のSVG似顔絵で描画されます。
1枚でも仮絵が混ざった回は、画像の上部に「仮素材」の黄色い帯が出ます
（全部そろうと自動で消えます）。

### キャラクター（3人）

| キャラ | 名前 | 役どころ |
|---|---|---|
| `senpai` | 先輩 | AIに詳しい先輩社員。ツッコミ役で、最後にオチをまとめる |
| `shinjin` | AI新人くん | AIそのものを擬人化した新人。素直だが極端に解釈してボケる |
| `buchou` | 部長 | 流行りに飛びつく管理職。世間の反応を代弁して無茶を言う |

### 表情（6つ）

`normal` / `smile` / `surprise` / `worry` / `think` / `shine`

3人 × 6表情 = **18枚**そろえば完成です。追加のコストはここだけ。

## 絵の仕様

- **バストアップ**（腰から上）。コマの下端で切れる前提で構図をとる
- 縦長。**高さ1000px以上**、背景は**透過**（PNG or WebP）
- 顔の位置と大きさを18枚で揃える。ここがズレると、コマが切り替わったときに
  キャラが飛び跳ねて見える。1枚を下敷きにして表情だけ描き替えるのが確実
- 左右どちらを向いていてもよい。2人が出るコマでは、右側のキャラは
  自動で左右反転されて向かい合う（＝**左向き基準で描く**のが望ましい）

## 表情を足したい・キャラを増やしたいとき

`scripts/generate-daily-manga.mjs` の先頭にある `CAST` と `EXPRESSIONS` を編集します。
ここがそのままClaudeに渡すスキーマの `enum` になっているので、
**ここに書いていない名前は生成されません**（＝画像だけ置いても使われない）。

キャラを増やすときは、仮素材のSVG（`placeholderSvg`）にも
その名前の分岐を足しておくこと。無いと `undefined` が描画されて崩れます。

## 動作確認

APIを叩かずに、見本データで描画だけ試せます。

```bash
npm run daily:manga -- --sample --force
```

`public/daily/<日付>.png` と `public/og/daily/<日付>.png` が出ます。
確認したらこの2枚とentries.jsonの中身は消しておくこと
（見本の4コマは実在するニュース見出しと結びついていないので、公開してはいけない）。
