# 白紙のLP — MVの猫キャラ画像置き場

3問目「いまほしいもの」の回答ごとに、ここへwebpを置くだけでMVに反映される。

| ファイル名 | 対応する回答 |
|---|---|
| learn.webp   | 基礎から学びたい（先生ネコ） |
| make.webp    | なにか作ってみたい（組み立てネコ） |
| work.webp    | 明日の仕事で使いたい（仕事がはかどるネコ） |
| consult.webp | 仕事を相談したい（受付ネコ） |
| default.webp | 汎用（白紙に描き起こすネコ）。上のどれかが無いときのフォールバック兼用 |

- 静止画でもアニメWebPでもOK（imgタグで表示している）
- どれも無ければ従来どおり /hero-logo.jpg にフォールバックする
- 動画素材(mp4等)しか無い場合は変換が必要なのでClaude Codeに投げること
