# 白紙のLP — MVの猫キャラ動画置き場

3問目「いまほしいもの」の回答ごとに、MVでループ再生される猫キャラの動画。
`{key}.mp4`（本体・シームレスループ済み）と `{key}.webp`（ポスター/読み込み中表示）のペアで置く。

| key | 対応する回答 | シーン |
|---|---|---|
| learn   | 基礎から学びたい | 先生ネコ（黒板） |
| make    | なにか作ってみたい | 組み立てネコ（積み上げ） |
| work    | 明日の仕事で使いたい | 仕事がはかどるネコ（ノートPC） |
| consult | 仕事を相談したい | 受付ネコ（カウンターとベル） |
| default | 汎用・フォールバック | 白紙に描き起こすネコ（画板） |

- 動画が再生できない環境では /hero-logo.jpg に自動フォールバック
- 差し替え時の加工（リサイズ・ループ化・軽量化）はMidjourney素材のmp4を
  Claude Codeに投げれば一括でやってくれる
  （加工内容: 832x464 / 24fps / つなぎ目0.5秒クロスフェード / h264 crf27 / 目安300KB）
